# 四套底栏概念

渲染在 `design/navbar/renders/`。每个概念一张深色、一张浅色。动效预览约 5.3 秒：先停在概览，再切到玩家、再切到控制台，最后按下快捷动作。尘迹、点阵、游标的预览是深色；纸页的预览是浅色。

地图从底栏拿掉，作为概览里的一张「轻收容区」卡片。快捷动作始终是三件事：广播、重启回合、CASSIE。重启回合用危险色，因为它不可撤销。

源文件在 `design/navbar/src/`（`app.js` 按时间纯函数绘制，方便逐帧截图）。重新出图需要本机 Chrome 和 puppeteer-core：`node design/navbar/src/capture.mjs` 出静帧，加 `--videos` 出预览。

## 尘迹

底栏没有胶囊，也没有一块更深的底板，只有一条 1.5px 的分割线。四项在左，右侧用一条细竖线隔开圆形「操作」键。图标是 1.7px 圆头单线：概览是带标题栏的窗口，玩家是一大一小两个人，控制台是 `>_`，中心是三枚方框加右下角那一粒点。每一枚图标都有一粒脱离轮廓的点，这是这套语言的签名。未选中是中性灰，选中变成墨色，那一粒点变成淡紫。

粒子只做四件事。待机时分割线上方有不到十粒尘，沿水平方向很慢地漂，颜色在樱粉、淡紫、天蓝之间换。选中项的标签下有三粒几乎不动的色点，用来标明当前位置。切换时，旧图标拆成小点、新图标从散点聚回，大约 600ms，停住之后立刻恢复成实线，避免一直发虚。按下操作键时，十余粒尘从键里向上扬起再落下，同时出现三个扁圆按钮。

深色底 `#10151C`，卡片 `#161B22`。浅色是暖纸 `#F4F1EB`，卡片近白，粒子改用更深的樱粉和淡紫，保证在浅底上还能看见。

### Compose

图标用 `ImageVector`，圆头 `StrokeCap.Round`，签名点是矢量里的一个圆。底栏用透明 `NavigationBar` 或普通 `Row`，顶上 1dp 分割线，不调用 `liquidGlass`。

粒子放在底栏上方约 48dp 的 `Canvas` 里，用一块预分配的 `FloatArray`（不超过 36 粒）。`LaunchedEffect` 里 `withFrameNanos` 更新，只 `invalidate` 这块画布。切换动画不要在运行时把 `ImageVector` 光栅化：每个图标预写 16 到 24 个采样点，用进度做插值。进度到头就改回 `Icon`。

按下的三粒选项用现有的 `Popup` 或一行 `Surface`，重启回合走 `colorScheme.error`。按下缩放可以沿用 `Glass.kt` 里那种 spring（约 0.97），即使玻璃是关的。

性能：粒子只脏底栏那一条，中端机 60fps 足够。不要为每粒尘建一个 Composable。

API 31 以下、33 以下：这套不依赖模糊和折射，外观和 Android 14 相同。`prefers-reduced-motion` 或系统「移除动画」时，跳过拆散，图标做 150ms 交叉淡化，三粒选中点保持静止。

## 点阵

底栏是一件东西：一条圆角键床，右侧空开一条缝，再加一枚同样高度的方键。没有高光、没有模糊。图标是 7×7 点。未选中的点更小、更淡；选中的点更大、用墨色。操作键里是一枚加号点阵，标签写在键内。

切换时，点从旧位置散开十几像素再落到新图标上，本身就是粒子，不再另加拖尾。待机时，未选中图标里有一个点在缓慢改变透明度，像待机灯；选中项标签下有两粒色点（樱粉和淡紫）轻轻浮动。按下方键时，八粒点从加号中心沿八个方向走出再消失，键本身下移 2px。

概览里的地图也用点拼房间，和底栏是同一种材料。大数字用等宽字体，标签仍是黑体。

### Compose

点阵不要拆成几十个 `Box`。一个 `Canvas` 画完全部的点，或者每个图标一个由圆组成的 `ImageVector`（未选中 / 选中两套半径）。方键是 `Surface`，1dp 描边，`shadowElevation = 0`，按下用 `offset` 而不是发光。

同时可见的点不超过 80 个（四个 7×7 加方键）。这在中端机上可以忽略。

API 31 / 33：同样不需要 Backdrop。低版本和减少动画时，点直接交叉淡化，不做位移。

风险：控制台的 `>_` 在 7×7 里最容易看糊。正式做的时候用真机距离看一眼；如果认不出，就把这一枚改成更疏的单线 chevron，其余图标保持点阵。

## 游标

底栏仍然没有底板。选中标记是标签下方一枚淡紫方块，会以大约 1 秒的周期眨眼，和标题旁边、控制台输入行里的方块是同一种东西。图标只用直线和方块：概览是缺角的矩形，玩家是两个方头的人，控制台是 `>_`，中心是三个空方块加一个实心方块。操作键是描边方块，里面再套一枚小方块，下面写「操作」。

粒子是方块，不是圆。光标从一项滑到另一项时，后面留下 5 枚逐渐变淡的小方块。待机时，光标右侧有一两枚很小的方块在漂。按下操作键时，几枚方块从键的下沿落下，带一点重力，然后出现三行命令：`> 广播`、`> 重启回合`、`> CASSIE`。

页面更接近一份终端文档：统计不用卡片盒子，地图和阵营用分割线隔开。数字用等宽。

### Compose

光标的位置用一个 `Animatable<Float>` 或 `animateDpAsState` 跟着当前 index 走，画一个 32×8dp 的圆角矩形即可。眨眼只改这枚方块的 alpha，`infiniteRepeatable`，减少动画时停在不透明。残影是一个长度 6 的环形缓冲，每次位移推入旧坐标，寿命 400ms。

图标是 `ImageVector`，`StrokeCap.Square`。方块光标可以是矢量的一部分，选中时单独做 alpha；未选中不画实心方块，避免五项同时眨眼。

性能：6 个矩形。全 API 等级同一套画法。菜单用一列 `TextButton`，危险项用 error 色。

这是四套里实现量最小的一套，也和现有应用图标 `>_` 最齐。

## 纸页

这一套按 `anthropic-style-cn` 的数据看板模式来，浅色是主方案。页面底 `#ECE9E0`，卡片 `#F5F3EC`，字 `#141413`，唯一强调色是陶土橙 `#D97757`。左上角有一小团 6% 透明度的橙色径向晕。标题「概览」用霞鹜文楷（规范里的中文衬线），字重 400；「1939 Games」、导航和按钮用 Poppins 配思源黑体；大数字 18、60、12:34 用 Lora。深色用规范里的暗色令牌：底 `#1A1916`，卡片 `#222119`，字 `#EAE7DC`，橙色不变。

信息是不对称的：左侧是大号 18 / 40，右侧是 TPS 和回合，不是三张等大的 KPI。阵营条只用规范图表色（橙、蓝、橄榄、沙色）。底栏是一条抬起的纸，顶上 1px 线。图标很小，字才是导航：概览是四格、玩家是一个人、控制台是 `>_`、中心是一个圆点。选中项下面有 32×4px 的橙色短线。「操作」是橙色文字，和四项之间有一条竖线。

按下后是一张纸菜单。重启回合用 `#C0453A`，不用橙色，也不用灰色。

粒子是可选的纸屑：页脚附近不到十粒 1.5px 的灰点，切换时橙色短线两端掉下三四粒。可以整段不实现，栏的识别度不靠它们。

### Compose

浅色主题单独做一套 `ColorScheme`，不要把现在的樱粉主色混进来。中文标题用霞鹜文楷子集，界面用思源黑体 / Noto Sans SC 子集，数字用 Lora。只打包界面里出现的字，三份子集都可以很小。

底栏是 `Surface`，颜色用抬起色，1dp 顶边，无阴影，无 Backdrop。橙色短线用 `animateDpAsState` 平移。菜单是 `DropdownMenu` 风格的卡片，危险行的文字色是 error。

API 31 / 33：不使用玻璃。深色跟着系统，令牌按规范的暗色表，强调色不反转。减少动画时短线瞬移，纸屑不画。

和现有夜间值守场景的距离最远。适合作为「白天 / 纸感」的另一条品牌探索，不适合直接替换现在的深色控制台。

## 建议先做哪一套

先做尘迹。

它同时接住这轮的三个要求：栏本身很静，粒子是唯一的装饰而且每次出现都有事由，图标也不是 Material 的那一套。静帧里四枚图标还能认（窗口、两个人、提示符、四个格子），快捷动作和分页是分开的两件东西。实现落在 `ImageVector` 加一块很小的 `Canvas` 上，不碰 Backdrop，所以 Android 12 以下不用做降级外观。

点阵辨识度更高，但控制台那一枚在 7×7 里最吃力，适合作为第二套原型，用真机距离确认可读性之后再决定要不要替换尘迹。游标的实现量更小，如果希望第一版就和现有 `>_` 图标完全是同一种东西，可以用它替换尘迹的图标语言，粒子系统几乎可以原样留下。纸页留作独立方向，不进这一次的夜间底栏。
